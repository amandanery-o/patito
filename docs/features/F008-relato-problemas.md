# F008 — Relato seguro de problemas

## Requisitos

`REQ-007`, `REQ-019`, `REQ-049`, `REQ-058`, `REQ-061`

## Resultado

Problemas técnicos e pedagógicos chegam ao GitHub com contexto suficiente e sem identificar a criança.

## Regras

- O navegador envia o relato a uma função segura no servidor.
- Somente o servidor possui credencial para criar issues.
- Nome, e-mail, ID do aluno e respostas pessoais nunca são enviados ao GitHub.
- O relato pode incluir matéria, conteúdo, ID da questão, descrição, versão e dados técnicos não pessoais.

## Critérios de aceite

- O aluno consegue reportar uma questão ou problema geral.
- Uma issue estruturada é criada no repositório configurado.
- O conteúdo da issue não identifica o aluno.
- Falhas no GitHub são registradas e comunicadas sem perder silenciosamente o relato.
